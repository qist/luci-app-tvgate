# luci-app-tvgate

LuCI app for TVGate on OpenWrt.

[中文文档](README_zh.md)

## Description

TVGate is a high-performance local network resource forwarding and proxy tool. It can forward internal network resources (such as http, https, rtsp, rtp) to the external network through HTTP, allowing external network users to access streams or request proxy resources by accessing the port (default 8888) of the Go program host.

## Features

- Automatically detects system architecture and downloads the appropriate TVGate binary
- Supports GitHub release acceleration via proxy (e.g., https://hk.gh-proxy.com/)
- Web UI for easy configuration and management
- Real-time display of service status
- Support for multiple architectures (x86_64, aarch64, armv7l, etc.)

## Installation

### Option 1: download the prebuilt package (recommended)

Packages are built by CI on every tag push and published to Releases:

<https://github.com/qist/luci-app-tvgate/releases/latest>

| System | Format | Asset |
|---|---|---|
| OpenWrt 22.03 / 23.05 | opkg (`.ipk`) | `openwrt-22.03.5-luci-app-tvgate_<version>_all.ipk` |
| OpenWrt 25.12+ | apk-tools (`.apk`) | `openwrt-25.12.0-rc2-luci-app-tvgate-<version>-r1.apk` |
| i18n (optional) | same | `openwrt-*-luci-i18n-tvgate-zh-cn-*`, `openwrt-*-luci-i18n-tvgate-en-*` |
| Checksums | - | `sha256sums.txt` |

> Packages are architecture-independent (`all` / `noarch`); x86_64 is only the build target.

**opkg (OpenWrt 22.03 / 23.05)**

```bash
cd /tmp
opkg update
opkg install curl ca-certificates unzip luci-compat luci luci-base
opkg install libustream-openssl ca-bundle
opkg install ./openwrt-22.03.5-luci-app-tvgate_*_all.ipk
opkg install ./openwrt-22.03.5-luci-i18n-tvgate-zh-cn_*_all.ipk   # optional
```

**apk-tools (OpenWrt 25.12+)**

```bash
cd /tmp
apk update
apk add curl ca-certificates unzip luci-compat luci luci-base
apk add --allow-untrusted ./openwrt-25.12.0-rc2-luci-app-tvgate-*.apk
apk add --allow-untrusted ./openwrt-25.12.0-rc2-luci-i18n-tvgate-zh-cn-*.apk   # optional
```

**Verify / uninstall**

```bash
sha256sum -c sha256sums.txt          # verify downloads (optional)

opkg remove luci-app-tvgate luci-i18n-tvgate-zh-cn   # opkg
apk del luci-app-tvgate luci-i18n-tvgate-zh-cn       # apk
```

### Option 2: build from source / SDK

```bash
# Put this repo under package/ of an OpenWrt tree or SDK.
# The SDK ships no feeds, so luci.mk / po2lmo must be installed first:
./scripts/feeds update luci
./scripts/feeds install luci-base

# Select the package before compiling (otherwise compile produces nothing)
echo "CONFIG_PACKAGE_luci-app-tvgate=m" >> .config
make defconfig
make package/luci-app-tvgate/compile V=s
```

Output: `bin/packages/<arch>/base/luci-app-tvgate_<version>_all.ipk` (`.apk` on OpenWrt 25.12+).

## Configuration

After installation, you can configure TVGate in the LuCI interface:
1. Navigate to Services -> TVGate
2. Configure the download proxy if needed (e.g., https://hk.gh-proxy.com/)
3. Click "Download/Update Binary" to download the TVGate executable
4. Enable the service and configure the listening ports
5. Save and apply the settings

## Usage

Once the service is running:
- Access the web interface at `http://[router-ip]:[config-port]/[config-web-path]` to manage settings
- Access IPTV streams at `http://[router-ip]:[config-port]/[proxy-url-path]`

## Technical Details

- The app automatically detects the system architecture and downloads the corresponding binary
- ZIP format is used for releases, automatically extracted after download
- Service managed through procd with automatic restart capability
- Configuration file is automatically generated by TVGate itself

## Supported Architectures

- x86_64 (amd64)
- i686/i386/i486/i586 (386)
- aarch64/arm64 (ARM64)
- armv7l/armv7 (ARMv7)
- armv6l/armv6 (ARMv6)
- armv5l/armv5 (ARMv5)
- loongarch64/loong64 (LoongArch)
- mips64el (MIPS64 Little Endian)
- mips64 (MIPS64)
- mipsel/mipsle (MIPS Little Endian)
- mips (MIPS)
- ppc64le (PowerPC 64 Little Endian)
- ppc64 (PowerPC 64)
- riscv64 (RISC-V 64)
- s390x (IBM System z)
